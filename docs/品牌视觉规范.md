# 小黑屏品牌视觉规范

## 1. 品牌核心

“小黑屏”的视觉关键词是克制、专注、可靠。界面以接近纯黑的曜石底色承载内容，绿色只用于可操作项、当前选中项和正向运行状态，避免整屏高饱和造成注意力干扰。

品牌图形由“屏幕边框、月牙、状态点”组成：屏幕代表监督边界，月牙代表黑屏与休息，状态点代表任务持续运行。不得使用 Android 默认机器人图标，也不得单独拉伸或旋转品牌图形。

## 2. 颜色令牌

颜色的唯一代码来源为 `theme/Color.kt`；Compose、传统 View 和悬浮层均通过同一组语义令牌取色。

| 语义 | 色值 | 使用范围 |
| --- | --- | --- |
| Canvas | `#050806` | 页面、锁定页与启动背景 |
| SurfaceCard | `#0E1712` | 卡片与主要容器 |
| SurfaceRaised | `#142219` | 键盘按键、次级容器、选项底色 |
| Primary | `#21C76A` | 底部标签选中态、主按钮、活动状态 |
| PrimaryBright | `#55E58F` | 品牌图形高光，不用于大面积按钮 |
| Secondary | `#5AD7E6` | 信息提示和辅助分类 |
| AppAccent | `#91A7FF` | App 独立监督的类别识别 |
| Warning | `#F5C76B` | 需要人工处理但尚未失败 |
| Danger | `#FF6B72` | 锁定警告、删除、失败和终止操作 |
| TextPrimary | `#F4F7FA` | 标题、正文中的首要信息 |
| TextSecondary | `#AAB6C5` | 描述、时间和辅助信息 |
| TextTertiary | `#748296` | 弱提示与不可用状态 |

主色绿色不得同时表达错误。危险操作必须使用 Danger；信息提示优先使用 Secondary；App 监督的类别色不能替代主操作色。

## 3. 字体与层级

使用 Android 系统无衬线字体，不捆绑外部字体，避免安装包膨胀和字形缺失。所有字号使用 `sp`，完整字阶定义在 `theme/Type.kt`：

- 大倒计时使用 Display 字阶与粗体。
- 页面标题使用 Title Large 或 Headline Small。
- 正文使用 Body Medium/Large。
- 辅助说明不小于 Label Small，并保持足够行高。
- 不使用全大写英文作为主要操作文案。

## 4. 圆角、间距与交互

圆角统一由 `theme/Shape.kt` 提供：小控件 8–12 dp、普通卡片 16 dp、重点卡片 22 dp、模态容器 30 dp。基础间距按 4 dp 网格组合，常用页面边距为 18 dp。

可点击区域最小为 48 × 48 dp。选中状态不能只依赖颜色，还应同时具备位置、图标或文字状态。主操作按钮使用绿色底和深色文字；底部标签选中态使用绿色图标、绿色文字和深绿色指示底。

## 5. 图标与启动体验

- 自适应图标使用独立背景、前景和 Android 13 单色图层。
- 前景关键内容保持在自适应图标安全区内，圆形、圆角矩形和厂商异形蒙版均不得裁掉屏幕边框。
- API 26 以下兼容资源保留同一品牌图形；当前最低版本虽为 API 26，兼容资源仍用于部分厂商启动器回退。
- Android 12 及以上启动页使用品牌 Canvas 背景和自适应图标，避免白色闪屏。

## 6. 禁止项

- 禁止在业务组件中新增未经语义化的品牌十六进制颜色。
- 禁止使用白色页面背景或浅色系统边缘。
- 禁止用绿色表示“删除、结束监督、验证失败”。
- 禁止把品牌主色改成类别色，或让类别色抢占底部标签和主按钮层级。
